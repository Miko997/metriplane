# Reviewer Quickstart

The maintained camera-free reviewer path for the archived Metriplane `v0.2.0`
SoftwareX artifact is the [review kit](review_kit/00_start_here.md). Its exact
commands, expected outputs, and provenance are in the [SoftwareX reproduction
guide](softwarex_reproducibility.md).

Windows users must run the workflow inside WSL2 Ubuntu. The Bash commands are
not intended for native Command Prompt or PowerShell. Follow the
[platform and clean-run
preflight](softwarex_reproducibility.md#platform-and-clean-run-preflight) before
cloning.
