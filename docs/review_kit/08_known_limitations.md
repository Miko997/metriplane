# Review Kit Known Limitations

- The review kit is camera-free and replay-based.
- The assembly-cell case covers one checked-in deterministic scenario.
- The evidence is planar XY and depends on tagged/fiducial assets.
- The software is observe-only and does not control robots or machines.
- The software is not safety-certified and does not approve quality release.
- No marker-free tracking claim is made.
- Docker runtime and Isaac Sim runtime were not run for this package.
- Existing ROS 2 and Omniverse evidence remains bounded to its documented manual scope.
- v0.2.0 remains a release candidate until the GitHub tag and Zenodo archive exist.
