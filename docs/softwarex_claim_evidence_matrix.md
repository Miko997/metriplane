# SoftwareX Claim Evidence Matrix

This matrix maps manuscript-safe Metriplane v0.2.0 claims to exact repository or
public evidence. It is intentionally conservative: it separates the archived
software artifact, the frozen evidence package, current `main`, and reported
external feedback.

The `Paper section` column is a conservative placement guide for manuscript
writing. It is not a claim that the final manuscript must use that exact
section title.

Human-facing manuscript prose should use `Metriplane`. Technical identifiers
remain lowercase where the software uses them, for example `metriplane`, CLI
commands, paths, package names, and URLs.

Status values:

- `PASS`: supported by inspected repository or public evidence.
- `CAUTION`: usable only with the stated limitation or provenance note.
- `DO NOT CLAIM`: unsupported or contradicted by inspected evidence.
- `NEEDS AUTHOR CONFIRMATION`: reported or requested by the author, but not
  independently present in the repository or public issue evidence inspected
  during this audit.

Reviewer reproduction commands below use temporary output directories. They are
intended to compare fresh outputs against the frozen archived evidence without
rewriting `evidence/paper_v2_0/`.
