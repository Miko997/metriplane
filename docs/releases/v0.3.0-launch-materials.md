## Short technical announcement

> Metriplane v0.3.0 is available. Give it timestamped object positions and
> process rules; it replays the recorded workcell run and creates an incident
> timeline, Incident Report, verified evidence bundle, and repeatable regression
> check. The bundled camera-free demo finds a missing torque driver, a
> 35.0-second fastening delay, six events, and one incident.
>
> Try it:
>
> `python -m pip install "metriplane==0.3.0"`
>
> `metriplane demo --open`
>
> Linux/Ubuntu is fully tested on Python 3.12 and 3.13. The bundled camera-free
> demo is tested on macOS with both versions. The owner reports one successful
> bundled-demo run from native Windows Command Prompt, but broader native-Windows
> support is not claimed. WSL2 Ubuntu 24.04 has a bounded manual Python 3.12.3 validation for the
> installed-wheel camera-free and headless path. Automatic browser opening is
> not claimed there; users can omit `--open` or open the report path manually.
> Metriplane analyzes recorded state and does not control machinery or certify
> safety or quality.

The production-PyPI installation and the exact artifact hashes above were
verified by the publication workflow before this announcement was finalized.
