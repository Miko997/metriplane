## Build-once publication and readback

The annotated tag workflow is the only producer of the publication artifact
set. It runs the release gates and complete suite, builds exactly one wheel and
one source distribution, records `SHA256SUMS`, validates both distributions,
publishes the retained files to TestPyPI, and reads them back.

Production promotion is a separate owner-only dispatch from current protected
`main`. It names the successful tag run and exact version, acquires the
App-owned release lease, downloads the retained `python-package-distributions`
artifact, compares it with TestPyPI, and publishes those same bytes to PyPI. Do
not rebuild, rename, edit, or substitute any distribution between qualification,
TestPyPI, and production.

After publication, compare the production registry hashes with `SHA256SUMS`,
install `metriplane==0.4.0.post1` in a new clean environment outside the checkout, and
run package checking, version, doctor, and bounded product smoke. An ambiguous
upload or any hash disagreement is a release incident; do not retry by rebuilding.
