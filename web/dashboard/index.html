Metriplane 2.0

A measured operating layer for physical spaces.

The 2.0 release keeps the original camera-to-coordinate foundation, then adds the operational layers teams need to inspect, explain, and trust what happened on the floor.

Layer 01

Camera calibration and metric state

Ordinary camera views become real-world XY coordinates, object IDs, zones, and runtime telemetry.

Layer 02

Live runtime and replayable evidence

Frame state, zone events, JSONL runs, and health signals are emitted in structured formats.

Layer 03

Sentinel audit and risk layer

Observe-only contracts, incidents, camera trust, and short-horizon forecasts sit above the state stream.

Layer 04

Command Center for operators

A read-only interface turns runs into map state, incident context, trace summaries, and grounded answers.

Capabilities

Core platform capabilities

A complete path from calibrated camera input to live state, operations context, evidence, and integrations.

Metric World State
Camera detections become real-world planar coordinates with object IDs and zone membership.
Runtime Telemetry
Stream frame state, zones, health, and latency through WebSocket and structured JSON outputs.
Command Center
A read-only operations view for map state, objects, incidents, traces, and operator questions.
Sentinel Contracts
Observe-only rules over zones, object types, minimum distance, dwell time, and restricted areas.
Camera Trust
Rank camera reliability from dropout, disagreement, confidence, and zone coverage.
Risk Forecasting
Project object motion over a short horizon and record likely contract violations.
Grounded Assistant
Answer run questions from local artifacts with citations and no external LLM.
Evidence & Integrations
Run summaries, replay logs, read-only endpoints, schema docs, exports, and external dashboards.
