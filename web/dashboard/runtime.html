Quick Guide

▾ Full Runbook
1
Understand Live State
The Live State panel streams real-time object positions, zone events, and camera telemetry via WebSocket (:8765). Start a run first to see data.
2
Check System Health
The System Health panel (right column) polls the health endpoint (:8000/health). Green = all components OK. Red = check stderr or run doctor.
3
Investigate Evidence
The Evidence Manifest table summarises all benchmark results recorded in evidence/manifest.csv. Serve the dashboard from the repo root to load it.
4
Configure & Validate
Use the Operator Setup wizard to calibrate cameras, define zones, and start a fusion run — all without direct terminal access beyond starting the runner.
